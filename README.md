## 🌟 一、项目介绍

欢迎来到 **UMX 创意工坊（UMX Creative Studio）**！

这是一个整合多种 AI 创作技能（Skills）的专业创意制作系统，旨在建立一套完整、规范、可复用的 AI 辅助创作与影视制作体系。

本项目涵盖人物设计、剧本创作、动画制作、音乐制作、MV 制作及真人影视制作等多个领域。

通过不同的专业 Skill 相互配合，让创作者能够从最初的创意构思，一步步完成完整的作品制作。

### 🎯 项目核心目标

- 建立完整的 AI 创意制作生态系统。
- 统一人物设计及视觉表现标准。
- 提高不同制作版本之间的人物一致性。
- 整合剧本、分镜、音乐与视频制作。
- 建立可重复使用的专业 Skill 工作流程。
- 支持原创动漫、影视、音乐及游戏 IP 开发。
- 为未来大型原创宇宙作品提供制作基础。

- 人物多角度头像
- 人物面部表情设定
- 发型与发色设计
- 服装与配饰设计
- 人物身体比例设定
- 人物色彩方案
- 人物道具及装备设计
- 参考图片直接植入
- AI 图片生成提示词
- 专业角色设定板排版

**输出内容：** 完整人物设定集、人物三视图、多角度头像、服装及道具细节。

**主要用途：** 制作适合 2D 动态漫画的原创人物。

# 📖 八、使用方法

每个 Skill 都可以独立使用，也可以与其他 Skill 配合。

**基本使用流程：**

1. 根据创作需求选择对应 Skill。
2. 提供作品概念、人物资料或参考图片。
3. 按照 Skill 的指令执行制作。
4. 生成对应剧本、提示词或视觉设定。
5. 检查人物、剧情及场景一致性。
6. 将制作结果导入对应 AI 工具。
7. 完成最终作品制作。
