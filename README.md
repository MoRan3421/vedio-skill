## 🏛️ 00｜知识库首页
UMX 超元宇宙 AI 创作技能知识库。统一管理 AI Skills、MASTER PROMPTS、制作规范及专业工作流程。

## 👑 01｜人物角色设计中心
- A. 2D 动态漫画人物设计：外貌、五官、发型发色、服装、表情、多角度与画风一致性。
- B. 3D 国漫人物设计：三维造型、材质、发丝、服装物理、微表情、灯光。
- C. 真人影视人物设计：真人外貌、妆发、服装、摄影与人物连续性。
- D. 通用专业人物设定系统：三视图、多角度头像、表情板、服装细节、道具及设定板。

## ✍️ 02｜剧本创作中心
- A. 2D 动态漫画剧本：故事、场景、镜头、对白、动作、转场、音效、伏笔。
- B. 3D 国漫剧本：世界观、主支线、角色成长、战斗、电影镜头与连续性。
- C. 真人影视剧本：电影、电视剧、短剧格式、场景、对白、演员表演与摄影。
- D. 漫剧剧本总控：后续按完整原稿归档。

## 🎬 03｜动漫与影视制作中心
- A. 2D 动态漫画制作：角色一致性、背景、九宫格、镜头运动、动态效果。
- B. 3D 国漫制作：模型、电影摄影、口型、微表情、发丝布料、战斗与环境特效。
- C. 真人影视制作：演员形象、摄影、灯光、表演、服化道连续性、后期与视效。

## 🎵 04｜歌曲与音乐制作中心
- A. 原创主题曲；B. OP 片头曲；C. ED 片尾曲；D. BGM 背景音乐；E. MV 制作；F. 歌词与音乐创作。
- **OP、ED、主题曲、BGM、MV 全部归入本中心；MV 不另设一级分类。**

## ⚔️ 05｜分镜与视觉特效中心
- A. 分镜制作；B. 镜头设计；C. 战斗与视觉特效；D. 动作与舞蹈。
- 覆盖九宫格、摄影机位、运镜、动作、粒子、光影、转场与连续性。

## ⚙️ 06｜AI Skill 管理中心
- A. Skill 文件管理；B. 自动识别与分类；C. GitHub 自动化；D. 知识库维护。
- 自动扫描文本、识别标题与版本、生成索引、更新 README、提示重复与待确认项。

## 🌟 07｜团团官方视觉规范
- 官方发色体系、人物外观约束、视觉设计要求与页面风格。
- 角色原设定与发色不可因分类或迁移而擅自改写。

## 📚 08｜统一 Skill 文档规范
- 保留完整原始提示词；标注版本、用途、适用制作版本、来源与更新记录。
- 2D 动态漫画、3D 国漫、真人影视分别管理，不混写。

## 📝 09｜后续新增 Skill 登记规范
- 新增 Skill 必须登记分类、名称、版本、原始文件路径与更新日期。
- 每次新 Skill 同步进入 GitHub 与 Lark；双端核实后才标记完成。

## 📌 10｜官方管理原则
- 不编造不存在的 Skill，不用简介替代完整原稿。
- 不擅自删除或覆盖原始提示词。
- 分类不确定时标记待确认；原稿缺失时标记待补。
- GitHub 与 Lark 的分类编号、名称、子分类保持一致。
