## 统一归档规则
1. OP、ED、主题曲、BGM、MV 全部归入「歌曲与音乐制作」。
2. 2D 动态漫画、3D 国漫、真人影视分开保存，不混写制作版本。
3. 原始提示词全文优先；目录摘要只用于导航。
4. 无法核实原文的项目标记「待补原稿」，不虚构、不冒充已归档。
5. 自动识别不确定时标记「待确认」，不删除或改写原始文件。
