## 新增 Skill 双平台归档规则

每次新生成的 Skill 必须：

1. 保留完整原始提示词，建立独立文件。
2. 上传至 GitHub：  
   https://github.com/MoRan3421/vedio-skill/tree/main
3. 添加至 Lark 知识库：  
   https://njp79hrtgow3.jp.larksuite.com/wiki/UsX4whbC9iBUdkkVmX4jFrrtp4g
4. 按实际用途放入现有知识中心。
5. 更新 README、SKILLS_INDEX 和 Lark 分类目录。
6. 在回复用户时额外提供一段新增 Skill 登记说明。

**Lark 新增登记格式**

- 新增 Skill：
- 所属分类：
- 文件名称：
- 更新内容：
- GitHub 状态：
- Lark 状态：

未经核对的历史项目必须标记为待补原稿，不得伪装成已经完成。
