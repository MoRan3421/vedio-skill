## 01｜🎨 人物角色设计
- **2D 动态漫画人物设计**：五官、脸型、发型发色、服装、表情、多角度、画风一致性。
- **3D 国漫人物设计**：三维造型、材质、发丝动态、服装物理、微表情、灯光。
- **真人影视人物设计**：真人外貌、妆发、服装、表演参考、摄影与形象连续性。
- **通用人物设定集**：三视图、多角度头像、表情板、服装细节、道具与专业排版。

## 02｜📖 剧本创作
- **2D 动态漫画剧本**：故事、场景、镜头、对白、动作、转场、音效、伏笔与连续剧情。
- **3D 国漫剧本**：世界观、主支线、角色成长、战斗、电影镜头、特效与多集连续性。
- **真人影视剧本**：电影、电视剧、短剧格式、场景、对白、演员表演、摄影与拍摄连续性。

## 03｜🎵 歌曲与音乐制作
- 原创主题曲、OP、ED、BGM、插曲、配乐及 MV 视觉化制作。
- **MV 不设独立一级分类**，统一归入本类别。
- 当前已归档主题曲 Skill；MV 完整原稿登记为待补。

## 04｜🎬 动漫与影视制作
- **2D 动态漫画制作**：角色一致性、背景、九宫格、镜头运动、动态效果与剧集规范。
- **3D 国漫制作**：模型参考、电影摄影、口型、微表情、发丝与布料模拟、战斗及环境特效。
- **真人影视制作**：演员形象、摄影、灯光、表演、对白同步、服化道连续性、后期与视效。

## 05｜🎞️ 分镜与视觉特效
分镜与九宫格、镜头语言、摄影机位、运镜、动作设计、战斗特效、粒子、光影、转场与视觉连续性。

## 06｜🧠 AI Skill 管理
自动扫描 TXT/MD 等文本、分类识别、索引生成、README 更新、重复内容提示、版本记录与归档检查。

## 07｜🌍 世界观与 IP 开发
世界观、宇宙设定、人物关系、系列规划及跨媒体 IP 资料管理。

## 08｜🎮 游戏与互动内容
游戏系统、Roblox、玩法机制、互动世界与游戏视觉内容。
